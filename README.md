## 📌 About

Hi! I am a software developer passionate about writing clean code, exploring modern technologies, and building practical systems powered by **Artificial Intelligence, Shell Automation & Efficient Architecture**.

I enjoy turning ideas into functional software, focusing on building tools that are modular, fast, and privacy-conscious. My work spans high-throughput data processing utilities, autonomous AI assistants with terminal capabilities, and local-first desktop applications.

- **Software Development:** Writing clean, readable, and maintainable code with a strong focus on problem-solving and efficiency.
- **Shell & CLI Automation:** Writing robust Bash/Shell scripts and terminal workflows to automate system tasks, environments, and developer pipelines.
- **AI Systems & Automation:** Designing workflows, agents, and utilities integrating modern AI models (OpenAI, Claude, Ollama) with terminal tool execution.
- **Data & Local-First:** Developing streaming data processing utilities and offline-first software that keep sensitive data strictly on local storage.
